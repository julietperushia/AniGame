ANIGAME - YOUR ART GOES HERE
==============================
Drop files with these exact names (PNG recommended, transparent background unless noted), then run
Tools > AniGame > Steps > 4. Generate UI Art (or Build Everything). Missing files use generated placeholders.
Colour emoji can't be shown by Unity's legacy Text, so every icon must be a PNG.
